### 4. 对话中固化的关键概念

- **数学短板诊断**：概念扎实，但停留在 1D/线性/标量层，难点被通俗语言绕过；真正的数学（SO(3) 姿态参数化、协方差加权、预积分零偏雅可比、扫描匹配残差雅可比）尚未进入。
- **非线性在哪**：不是"旋转"本身，而是角度/旋转**钻进测量模型**（atan2、坐标变换）时。判据口诀——未知量只以加减/乘常数出现则 J 是常数；钻入 sin/atan2/相乘则 J 随估计值变。
- **高斯-牛顿流程**：算残差 r → 算雅可比 J → 解 (JᵀJ)δ = −Jᵀr → 更新；非线性导致 J 随估计值变 → 要迭代；会过冲 → LM 加阻尼 λI。
- **IMU 测什么**：角速度 ω（陀螺仪），不是朝向 θ；朝向 = ∫ω dt。漂移：陀螺零偏 → 朝向**线性**漂（一次积分），加速度计零偏 → 位置**二次**漂（两次积分）。
- **激光怎么得旋转**：扫描匹配找 T（旋转 + 平移的完整相对位姿），"找出 T"本身是高斯-牛顿迭代；激光**不累积漂**（每帧重新对照环境），IMU 累积漂。
- **位姿自由度阶梯**：1D → SO(2) → SE(2) → SO(3) → SE(3)，是"被估计的位姿"自由度递增、逼近真实。
- **前端 / 后端**：前端（扫描匹配算 T、预积分算 Δ）产**相对位姿测量**；后端（因子图）优化**绝对位姿轨迹**；两者都在优化位姿，**建图是副产品、不优化**。
